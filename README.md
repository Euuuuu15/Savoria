# Savoria

Ingredient-based meal recommendation website (static HTML, CSS, JavaScript).

## Run it locally
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension.
3. Right-click `index.html` > "Open with Live Server".
4. The page should say: "Setup works. Loaded 50 ingredients."

Do not double-click the HTML file. Browsers block loading JSON from `file://`.

## Structure
- `data/`  recipes, ingredients, categories (JSON)
- `css/`   styles, split by purpose
- `js/`    behavior, split by purpose
- `images/` recipe photos and the logo icon
- `admin/` admin prototype pages
- `docs/`  project brief and wireframes
